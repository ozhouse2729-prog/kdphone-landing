# 카피 규칙 (card.json 작성법)

카드 3장의 글자는 전부 `card.json` 하나로 들어간다. 디자인은 고정이고, 이 파일의 칸만 채운다.
숫자 기준은 `assets/rules.js`이며, 검사기(`scripts/render.js`)가 아래 규칙을 자동으로 검사한다.

## 1. 3장의 역할과 생김새

| 장 | 화면 | 역할 |
|---|---|---|
| 1p 썸네일 | 제품 사진 + 왼쪽 위 로고 + 왼쪽 아래 큰 흰 제목 3~4줄 (그 외 글자 없음) | "왜?", "뭐가?" 궁금증을 만들고 답은 주지 않는다 |
| 2p 내용 `1.` | 어두운 사진 배경, 가운데 정렬. 따옴표 제목 → 문단 2개 → 결론 1줄(보라 형광펜) | 1p의 궁금증에 사실로 답한다 |
| 3p 정리 `2.` | 같은 배경. 제목 → 전작 비교 3줄(이전 → 이번) → 아쉬운 점 2줄 → 결론 1줄 | 장점만 늘어놓지 않는다 |

## 2. 형식

```json
{
  "meta": {
    "product": "",
    "status": "공식 | 루머 | 유출",
    "date": "YYYY-MM-DD",
    "sources": [{ "name": "", "url": "" }]
  },
  "cover": {
    "title": ["", "", "", ""],
    "imageBrief": ""
  },
  "detail": {
    "headline": "",
    "paras": ["", ""],
    "conclusion": ""
  },
  "summary": {
    "headline": "",
    "compareWith": "",
    "rows": [
      { "item": "", "prev": "", "next": "" },
      { "item": "", "prev": "", "next": "" },
      { "item": "", "prev": "", "next": "" }
    ],
    "cons": ["", ""],
    "conclusion": ""
  }
}
```
키를 추가·삭제·개명하지 않는다. 모든 값은 한국어 문자열이다.

## 3. 글자 수 (공백 포함, `[[ ]]` 기호 제외)

| 칸 | 최대 |
|---|---|
| meta.product | 14자 |
| cover.title 한 줄 | 11자 (따옴표 포함) |
| cover.imageBrief | 80자 |
| detail.headline / summary.headline | 22자 |
| detail.paras[] | 60자 |
| detail.conclusion / summary.conclusion | 34자 |
| summary.compareWith | 14자 |
| summary.rows[].item | 5자 |
| summary.rows[].prev / next | 11자 |
| summary.cons[] | 24자 |
| meta.sources[].name | 20자 |

## 4. 개수
- cover.title 3~4줄 (배열 한 칸 = 화면 한 줄)
- detail.paras 정확히 2개
- summary.rows 정확히 3개
- summary.cons 정확히 2개
- meta.sources 1~3개

## 5. 1p 제목 (cover.title)
- 기본 구성: `[제품명] / “[궁금증] / [이어지는 말]” / [후킹]`
  - 예: `["갤럭시 S25", "“가격은 그대로,", "뭐가 달라졌을까?”", "핵심만 정리했다"]`
  - 예: `["아이폰 17 에어", "“5.6mm 두께에", "배터리는 괜찮을까?”", "써보면 다른 점"]` (숫자는 기사로 확인된 경우만)
- 따옴표는 `“ ”` 한 쌍까지. 여는 `“`는 줄 맨 앞, 닫는 `”`는 줄 맨 끝. 안 써도 된다.
- 형광펜 `[[ ]]` 금지 (1p는 전부 흰 글씨)
- 물음표는 제목 전체에서 최대 1개, 줄 끝 마침표 금지
- 루머·유출 기사면 "루머/유출/소문/예상/전망" 중 하나를 제목에 넣는다
- 제목은 의미 단위로 줄을 나눈다. 조사 앞에서 끊지 않는다.
- 궁금증은 기사 내용으로 답할 수 있어야 한다. 2p·3p에서 답하지 않는 질문을 던지지 않는다.

## 6. 보라 형광펜 `[[ ]]`
- detail.headline, summary.headline: 각 1~2개, 핵심 단어만 (문장 전체 X)
- detail.paras: 문단마다 0~1개, 15자 이하
- conclusion 두 칸은 자동으로 전체 형광펜. `[[ ]]` 쓰지 않음
- 그 외 칸은 금지
- 2p 제목의 따옴표 `“ ”`는 자동으로 붙는다. 1p 제목 외에는 따옴표를 쓰지 않는다.

## 7. 사실 규칙
- 모든 숫자·스펙·가격·날짜는 확인한 출처에 있는 것만. 기억·추측 금지.
- 확인 못 한 값은 "미공개". 빈칸을 그럴듯한 숫자로 메우지 않는다.
- 해외 가격만 있으면 원화 환산 금지 ("799달러").
- 표기: "115만 5천 원", "99만 원", "12GB", "4,000mAh", "45W", "120Hz"
- status: 제조사 공식 발표만 "공식". 외신·팁스터·인증기관 정보는 "루머"/"유출".
- compareWith: 같은 라인의 바로 이전 세대 (갤럭시 S25 → 갤럭시 S24, 아이폰 17 → 아이폰 16)
- rows: 칩셋·램·저장공간·배터리·충전·화면·카메라·무게·두께·출고가 중 차이가 큰 순서로 3개. 같으면 prev와 next를 글자까지 똑같이 (화면에 "(동일)" 자동 표시).
- cons: 출처나 스펙 비교로 확인되는 객관적 단점만. 취향 의견("디자인이 아쉽다") 금지.
- date: 기사 발행일. 본문에 "오늘·최근·곧" 같은 상대 표현 금지.
- sources: 실제로 읽은 기사 URL만.

## 8. 문체
- paras, conclusion: "~습니다"체 한 문장, 마침표로 끝
- cons: 명사형 종결 ("배터리는 전작과 같은 4,000mAh")
- summary.headline: 3p를 여는 말 ("[[전작 S24]]와 비교하면", "사기 전 [[알아둘 점]]")
- 금지 기호: `! ~ … ...` 이모지, `#`, 곧은 따옴표 `" '`, 꺾쇠 `「」『』<>`, 마크다운 `* _ \``
- 금지어: 충격, 경악, 역대급, 미쳤, 대박, 실화, ㄷㄷ, ㅋㅋ, ㅎㅎ, 무조건, 100%, 필수템, 끝판왕, 갓성비, 혁명, 완벽, 최초공개, 알고보니, 결국, 드디어, 난리, 소름, 모르면 손해
- 영어는 제품명·칩셋명·단위만
- 앞뒤 공백, 공백 두 칸 금지

## 9. cover.imageBrief
- 사용자가 찾을 "공식 보도자료 사진" 설명: 제품, 각도(정면/후면/측면), 배경 톤
- 1p에서 제품은 위쪽 60%, 아래는 제목. 세로 구도·어두운 배경이 좋다.

## 10. 완성 예시
```json
{"meta":{"product":"갤럭시 S25","status":"공식","date":"2025-01-23","sources":[{"name":"삼성전자 뉴스룸","url":"https://news.samsung.com/kr"}]},"cover":{"title":["갤럭시 S25","“가격은 그대로,","뭐가 달라졌을까?”","핵심만 정리했다"],"imageBrief":"갤럭시 S25 후면 카메라가 크게 보이는 공식 보도자료 사진, 어두운 배경, 세로 구도"},"detail":{"headline":"[[국내판도 스냅드래곤]], 램은 [[12GB]]","paras":["이번 S25는 국내 모델에도 [[스냅드래곤 8 엘리트]]를 넣어 지역별 칩셋 차이가 사라졌습니다.","기본 램도 8GB에서 12GB로 늘어 여러 앱을 띄워도 여유가 생겼습니다."],"conclusion":"가격은 그대로, 성능은 확실히 올랐습니다."},"summary":{"headline":"[[전작 S24]]와 비교하면","compareWith":"갤럭시 S24","rows":[{"item":"칩셋","prev":"엑시노스 2400","next":"스냅드래곤 8 엘리트"},{"item":"램","prev":"8GB","next":"12GB"},{"item":"배터리","prev":"4,000mAh","next":"4,000mAh"}],"cons":["배터리는 전작과 같은 4,000mAh","기본형은 여전히 25W 유선 충전"],"conclusion":"S23 이하 사용자라면 바꿀 만한 시점입니다."}}
```
(형식 참고용. 내용은 검증되지 않은 예시이므로 베끼지 않는다.)
