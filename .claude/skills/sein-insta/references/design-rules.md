# IT 카드뉴스 규칙서

## 0. 왜 이렇게 만들었나

AI에게 "이런 디자인으로 만들어줘"라고 하면 매번 결과가 달라집니다. 규칙을 아무리 길게 써도 AI는 그 규칙을 **참고**할 뿐 **지키지는** 않기 때문입니다.

그래서 일을 셋으로 나눴습니다.

| 역할 | 담당 | 바뀌는가 |
|---|---|---|
| 디자인 (색·폰트·배치·여백) | `assets/cards.css` 코드 | **절대 안 바뀜.** AI가 손댈 수 없음 |
| 글자 (제목·문단·비교) | Claude → `card.json` | 매번 바뀜. 단, 칸과 글자 수가 정해져 있음 |
| 검사 (규칙 위반 잡기) | `scripts/render.js` 검사기 | 위반이 하나라도 있으면 **저장 버튼이 잠김** |

---

## 1. 판형 · 공통

- **1080 × 1350px (4:5)**. 인스타 피드에서 가장 크게 보이는 비율
- 좌우 여백 **88px**: 프로필 그리드(3:4)에서 양옆이 잘려도 글자가 안전함
- 폰트 2종 (둘 다 굵기 1종, 가짜 굵게 처리는 꺼 둠)
  - **ONE 모바일고딕 Title**: 로고, 1p 제목, 번호(`1.` `2.`), 2·3p 제목, 결론 형광펜 줄, 3p 비교의 "이번" 값
  - **리디바탕**: 2p 문단, 3p 항목명·"이전" 값·아쉬운 점, 출처, 계정
  - 고딕 제목 + 명조 본문으로 대비를 줘서 "기사를 읽는" 느낌을 냄. 명조는 획이 가늘어 본문 크기를 37px 이상으로 둠
  - 폰트를 바꾸려면 `assets/fonts/`에 woff2를 넣고 `assets/fonts.css` 수정 → `node scripts/build-studio-fonts.js` 실행
- 색은 **흰 글씨 + 보라 형광펜(`rgba(140,92,230,.78)`)** 두 가지뿐. 다른 색을 추가하지 않음

## 2. 페이지별 설계

### 1p 썸네일 (참고 예시 1)
- 제품 사진을 화면 가득 깔고, 아래 40%만 검게 그라데이션
- 왼쪽 위에 **검은 말풍선 로고** 하나
- 왼쪽 아래에 **큰 흰 제목 3~4줄**. 그 외 글자 없음 (태그·페이지 번호·화살표 없음)
- 제목 구성: `제품명 / “궁금증 / 이어지는 말” / 후킹`
- 제목엔 색 강조 없음. 따옴표로만 리듬을 줌

### 2p 내용 (참고 예시 2)
- 1p 사진을 **어둡게(밝기 38%) 살짝 흐리게** 깐 배경
- 모든 글자 **가운데 정렬**
- 위에서부터 `1.` → **따옴표 제목**(핵심 단어에 형광펜) → 문단 2개(짧은 형광펜 0~1개씩) → **결론 1줄(전체 형광펜)**
- 맨 아래 가운데 인스타 계정

### 3p 정리 (2p와 같은 디자인 언어)
- 같은 어두운 사진 배경, 가운데 정렬
- `2.` → 제목(형광펜) → 전작 비교 3줄(`이전 → 이번`, 바뀐 값은 형광펜, 같은 값은 "(동일)")
  → 아쉬운 점 2줄 → 결론 1줄(전체 형광펜)
- 맨 아래 출처·기준일 + 인스타 계정

## 3. 사진 규칙 (사람이 지킬 것)
1. **제조사 공식 보도자료 사진만** 사용 (삼성 뉴스룸, 애플 뉴스룸 등)
2. **AI 생성 이미지 금지.** 없는 버튼, 틀린 카메라 배치 같은 "가짜 제품"이 만들어짐
3. 어두운 배경·세로 구도 사진. 예시 1처럼 조명이 강한 사진일수록 좋음
4. 제품은 슬라이더로 화면 위쪽 60% 안에 맞춤
5. 워터마크가 있는 타 매체 사진 금지, 가로 1080px 이상

## 4. 글 규칙 (AI가 지킬 것, 검사기가 잡음)

자세한 내용은 `copy-rules.md`에 있습니다. 검사기(`scripts/render.js`, 수동 모드는 `assets/studio.html`)가 자동으로 잡는 항목은 다음과 같습니다.

- 정의된 칸 외 항목 추가 / 필수 칸 누락
- 칸별 글자 수 초과 (공백 포함)
- 개수 (제목 3~4줄, 문단 2, 비교 3, 아쉬운 점 2, 출처 1~3)
- 형광펜 `[[ ]]` 위치·개수 (1p 제목은 금지, 2·3p 제목 1~2개, 문단 0~1개)
- 따옴표 `“ ”`: 1p 제목에만 한 쌍, 여는 건 줄 맨 앞·닫는 건 줄 맨 끝
- 루머·유출 기사인데 제목에 "루머/유출/소문/예상/전망"이 없음
- 금지어 23개, 이모지, 느낌표, 물결, 말줄임표, 곧은 따옴표, 마크다운 기호, 이중 공백
- **실제 화면 넘침**: 글자 수를 지켜도 화면에서 넘치면 탈락
- 커버 사진 미첨부

검사기가 **못 잡는 것**은 **사실 여부**입니다. 저장 전에 2p·3p의 숫자를 원문 기사와 한 번 대조하세요.

## 5. 규칙을 바꾸고 싶을 때
- 글자 수, 금지어: `assets/rules.js` 수정 → `references/copy-rules.md`의 같은 숫자도 수정
- 색·폰트 크기·배치: `assets/cards.css`만 수정
- 브랜드명·인스타 계정: `assets/rules.js` 맨 위 `brand`, `handle`
