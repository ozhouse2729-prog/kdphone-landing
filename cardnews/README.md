# IT 카드뉴스 스튜디오

신제품·IT 소식을 인스타 3장짜리 카드뉴스(1080×1350)로 만드는 도구입니다.
**AI는 글만 쓰고, 디자인은 코드로 고정, 규칙 위반은 검사기가 막습니다.**

## 만드는 순서 (5분)

1. **AI에게 글 받기**: `PROMPT.md`의 프롬프트를 복사하고 맨 아래에 기사 본문을 붙여 AI에게 보냅니다. JSON이 돌아옵니다.
2. **스튜디오 열기**: `studio.html`을 더블클릭해 크롬으로 엽니다.
3. **붙여넣기**: JSON을 왼쪽 칸에 붙여넣고 **적용 + 검사**를 누릅니다.
4. **사진 넣기**: 화면에 뜬 "찾을 사진" 설명대로 공식 보도자료 사진을 받아 올립니다. 슬라이더로 제품을 위쪽에 맞춥니다.
5. **검사 확인**
   - 초록색 "모든 규칙 통과" → **PNG 3장 저장**
   - 빨간색 위반 목록 → **수정 프롬프트 복사** → AI에게 붙여넣기 → 새 JSON으로 3번부터 반복
6. **사실 확인**: 2p·3p의 숫자를 원문 기사와 한 번 대조한 뒤 게시합니다.

처음이라면 **샘플 불러오기**로 완성본 모양을 먼저 보세요.

## 파일

| 파일 | 내용 | 누가 수정 |
|---|---|---|
| `PROMPT.md` | AI에게 보낼 프롬프트 + 수정 프롬프트 | 규칙 바꿀 때 |
| `RULES.md` | 디자인·사진·글 규칙서 (왜 이렇게 설계했는지) | 참고용 |
| `rules.js` | 검사기 기준값 (글자 수·금지어·태그·브랜드명) | 규칙 바꿀 때 |
| `cards.css` | 카드 디자인 | 디자인 바꿀 때만 |
| `studio.html` / `studio.js` | 편집·검사·저장 화면 | 건드릴 일 없음 |
| `schema.json` | AI 도구의 JSON 모드용 구조 정의 | 규칙 바꿀 때 |
| `sample.js` | 샘플 데이터 | - |
